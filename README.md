# 🚀 SwiftKek

[![Minecraft Version](https://shields.io)](https://spigotmc.org)
[![Language](https://shields.io)](https://oracle.com)
[![License](https://shields.io)](LICENSE)

**SwiftKek** — это легковесный плагин для серверов Minecraft (Spigot/Paper), разработанный на Java для версии 1.21.1.

---

## 🛠️ Особенности проекта

- **Версия API:** Полная совместимость со Spigot API 1.21.1.
- **Готовая сборка:** В репозитории уже доступен скомпилированный `.jar` файл для быстрой установки.
- **Скрипт компиляции:** Наличие `compile.bat` позволяет быстро пересобирать проект в Windows в один клик.

---

## 📂 Структура репозитория

- `SwiftKek.java` — основной исходный код плагина.
- `plugin.yml` — конфигурационный файл плагина для сервера (содержит команды, права и версию).
- `compile.bat` — пакетный файл для автоматической компиляции проекта.
- `SwiftKek v1.4.jar` — готовый к использованию плагин.
- `spigot-api-1.21.1.jar` — зависимость API, используемая для разработки и сборки.

---

## 📥 Установка плагина на сервер

1. Перейдите в раздел файлов репозитория и скачайте актуальный файл `SwiftKek v1.4.jar`.
2. Поместите скачанный файл в папку `plugins` вашего сервера Minecraft.
3. Запустите или перезапустите сервер (`/reload` использовать не рекомендуется).

---

## 💻 Сборка из исходников

Если вы хотите внести изменения в код и пересобрать плагин самостоятельно:

### Windows:
1. Убедитесь, что у вас установлен JDK (Java Development Kit) и путь к `javac` добавлен в переменные среды.
2. Запустите файл `compile.bat` двойным кликом.
3. Скрипт автоматически скомпилирует исходный код и обновит `.jar` файл.
